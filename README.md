# 🚗 Ti-Kar Backend

API RESTful pour une plateforme de covoiturage entre passagers et chauffeurs.

## 📦 Technologies utilisées

- Node.js
- Express
- MongoDB + Mongoose
- Multer (upload de fichiers)
- JWT (authentification)
- express-validator

## 🔧 Installation

```bash
git clone https://github.com/tonrepo/tikar-backend.git
cd ti-kar-backend
npm install
